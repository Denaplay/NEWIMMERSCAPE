# Immerscape

## Локальный запуск

Для интеграции с my-ERP сайт необходимо запускать через встроенный сервер-прокси:

```bash
npm start
```

После запуска откройте <http://localhost:3000>. Команда `npx serve .` раздаёт
только статические файлы и не проксирует my-ERP, поэтому браузер блокирует
внешний запрос по CORS.

Страница бронирования доступна по обоим адресам:

- <http://localhost:3000/booking>
- <http://localhost:3000/booking.html>

Чтобы выбрать другой порт:

```bash
PORT=8080 npm start
```
